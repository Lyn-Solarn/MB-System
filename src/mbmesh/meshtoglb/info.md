# Convert mesh .off or .obj into .glb

## Run

### Mesh obj to .glb
Compile: g++ -std=c++17 mesh_obj_to_glb.cpp -o mesh_obj_to_glb

Run: ./mesh_obj_to_glb ./obj_test_data/output.obj

### Mesh off to .glb

Compile: g++ -std=c++17 mesh_off_to_glb.cpp -o mesh_off_to_glb

Run: ./off_to_glb my_mesh.off
